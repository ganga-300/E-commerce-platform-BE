# StudyStuff — Full Stack E-Commerce Platform

## Overview

StudyStuff is a full-stack e-commerce platform designed specifically for college students to purchase stationery and everyday essentials. The platform provides a seamless shopping experience with secure authentication, role-based access, and efficient product management.

---

## Features

**Authentication & Authorization**
- JWT-based authentication
- Role-based access control (Admin, Seller, User)

**User Features**
- Browse products with search & filtering
- Add to cart & wishlist
- Secure checkout
- Order tracking

**Admin Dashboard**
- Manage users, products, and categories
- Update inventory
- Monitor platform activity

**Payment Integration**
- Razorpay integration for secure transactions

**Responsive UI**
- Clean and user-friendly interface
- Optimized for different screen sizes

---

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database & ORM
- PostgreSQL
- Prisma ORM

### Authentication
- JWT (JSON Web Tokens)
- Bcrypt

### Payments
- Razorpay

---

## System Architecture

The application follows a modular full-stack architecture:

- **Frontend (Next.js)** handles UI and user interactions
- **Backend (Express.js)** manages APIs and business logic
- **Database (PostgreSQL)** stores users, products, and orders
- **Prisma ORM** ensures clean and scalable data handling

---

## Key Functionalities

### User Flow
1. Sign up / Login
2. Browse products
3. Add items to cart or wishlist
4. Checkout and make payment
5. Track orders

### Admin Flow
1. Login as Admin
2. Add / update / delete products
3. Manage users and categories
4. Monitor orders

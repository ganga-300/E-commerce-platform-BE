📦 StudyStuff — Full Stack E-Commerce Platform
🚀 Overview

StudyStuff is a full-stack e-commerce platform designed specifically for college students to purchase stationery and everyday essentials.
The platform provides a seamless shopping experience with secure authentication, role-based access, and efficient product management.

✨ Features
🔐 Authentication & Authorization
JWT-based authentication
Role-based access control (Admin, Seller, User)
🛒 User Features
Browse products with search & filtering
Add to cart & wishlist
Secure checkout
Order tracking
🧑‍💼 Admin Dashboard
Manage users, products, and categories
Update inventory
Monitor platform activity
💳 Payment Integration
Razorpay integration for secure transactions
⚡ Responsive UI
Clean and user-friendly interface
Optimized for different screen sizes
🛠️ Tech Stack
Frontend

🏗️ System Architecture

The application follows a modular full-stack architecture:

Frontend (Next.js) handles UI and user interactions
Backend (Express.js) manages APIs and business logic
Database (PostgreSQL) stores users, products, and orders
Prisma ORM ensures clean and scalable data handling

⚙️ Installation & Setup
# Clone the repository
git clone https://github.com/your-username/studystuff.git

# Navigate to project directory
cd studystuff

# Install dependencies
npm install

# Setup environment variables
# (Create a .env file and add required keys)

# Run the development server
npm run dev
🔑 Environment Variables

Create a .env file and add:

DATABASE_URL=
JWT_SECRET=
RAZORPAY_KEY_ID=
RAZORPAY_KEY_SECRET=
